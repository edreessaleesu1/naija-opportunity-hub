Bulk Opportunity Import

Import up to 100 opportunities in one submission using JSON. Each opportunity must have a title, organisation, category, description and application link.

Maximum: 100 opportunities per submission.
JSON format example 
[
  {
    "title": "Graduate Internship Programme 2027",
    "organization": "Example Organisation",
    "category": "Internship",
    "description": "A graduate internship opportunity.",
    "eligibility": "Graduates from recognised institutions.",
    "location": "Nigeria",
    "deadline": "2027-01-30",
    "application_url": "https://example.org/apply",
    "source_url": "https://example.org",
    "status": "pending"
  }
]
Only submit opportunities you have checked. Duplicate titles are skipped. Entries marked as pending will not appear in the public opportunities section until approved.
